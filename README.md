# Claude Auto Flow

Claude Code用の自律ワークフロー・オーケストレータースキルです。「検討 → 計画 → 実装 → チェック&プッシュ」の一連の流れを、ユーザーへの確認なしに最後まで自動進行させます。

## 概要

`auto-flow` は以下のパイプラインを完全自律で実行するオーケストレータースキルです。

```
[調査(任意)] → 検討 → 計画 → 実装 → セキュリティチェック & プッシュ
   Haiku       Opus    Opus    Sonnet          Haiku
```

- 各フェーズはサブエージェントとして起動され、前フェーズの成果物が次フェーズに引き継がれる
- 各スキルに組み込まれた承認ゲート（「実装してください」待ち、プッシュ前確認など）は、本フロー内ではすべて自動承認として扱われる
- 唯一の停止条件は、セキュリティチェックで問題が検出された場合のみ

## 依存関係

このスキルは単体では動作しません。以下のリポジトリで公開されている5つのスキルを事前に `~/.claude/skills/` に配置しておく必要があります。

**[rapyutapazoo-design/claude-skills](https://github.com/rapyutapazoo-design/claude-skills)**

- `consultant-mode` — 検討フェーズ
- `plan-creator` — 計画フェーズ
- `researcher` — 調査フェーズ（任意）
- `safe-push` — チェック&プッシュフェーズ
- `git-workflow` — 単体利用のみ（auto-flow内では使用しない）

先に上記リポジトリの内容を `~/.claude/skills/` 配下に配置してから、本スキルをインストールしてください。

## インストール手順

```bash
mkdir -p ~/.claude/skills/auto-flow
cp SKILL.md ~/.claude/skills/auto-flow/
```

## 使い方

以下のいずれかのトリガーフレーズを含むメッセージを送ると起動します。

- 「オートフロー」
- 「auto-flow」
- 「自律実行して」
- 「自動で最後まで進めて」
- 「全自動で進めて」

### 調査フェーズを追加する場合

課題文に以下のいずれかを含めると、冒頭に調査（researcher）フェーズが追加されます。

- 「--research」
- 「調査込みで」

## モデル配分表

各フェーズはトークンコストが最小になるモデルを割り当てたサブエージェントで実行されます。

| フェーズ | モデル |
|---------|--------|
| 調査（任意） | Haiku |
| 検討 | Opus |
| 計画 | Opus |
| 実装 | Sonnet |
| チェック & プッシュ | Haiku |

## 唯一の停止条件

safe-push のセキュリティチェックで 🔴（シークレット漏洩・除外ファイル混入）が検出された場合のみ、プッシュせずに停止しユーザーへ報告します。それ以外（🟡注意・🟢問題なし）は自動承認で続行し、最後まで自律的に完了します。
